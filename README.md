   - **නව දින සහ වේලාවන් ඇතුළත් කිරීම (Add Data):** ඕනෑම වෙලාවක අලුත් දින, වේලාවන් සහ නම් පහසුවෙන්ම Add / Edit / Delete කළ හැක.

1. `index.html` ගොනුව ඔබගේ Browser එකෙන් Open කරන්න.
